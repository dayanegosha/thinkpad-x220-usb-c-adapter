# .thinkpad x220 usb-c adapter

корпус для USB-C разъёма питания ThinkPad X220, который можно напечатать на 3D-принтере.

внутрь устанавливается небольшая плата USB-C PD trigger семейства PDC004. она запрашивает у зарядного устройства 20 в и передаёт питание на штатный кабель ноутбука. USB-данные не используются.

готовая модель лежит в [`stl/X220_USB_C_adapter.stl`](stl/X220_USB_C_adapter.stl). размеры можно изменить в [`src/adapter.py`](src/adapter.py), после чего собрать STL заново.

## печать

- материал: PETG или ABS;
- карман для платы положить на стол;
- поддержки не нужны;
- перед сборкой проверить размеры и распиновку своей платы.

## сборка модели

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/adapter.py
```

чертежи находятся в [`docs/`](docs/).

работа с питанием может повредить ноутбук или зарядное устройство. перед подключением проверьте полярность и выходное напряжение мультиметром.
